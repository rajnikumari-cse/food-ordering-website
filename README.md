# Food Ordering Website

A simple food ordering website built using HTML and CSS.

## About

This project is a basic food ordering website where users can explore food items, view offers, check categories, and find contact information.

## Features

- Home section
- Food menu
- Food categories
- Special offers
- Order Now buttons
- Contact section
- Clean and simple design

## Technologies Used

- HTML5
- CSS3
